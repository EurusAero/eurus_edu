# Симулятор

Благодаря использованию режима PX4 SITL, симулятор работает на том же ROS-коде, что и настоящий дрон. Это позволяет разработчикам тестировать и отлаживать свои программы в виртуальной среде, не теряя доступа к большинству функций реального аппарата.

## Установка виртуальной машины

Для работы с симулятором необходимо установить и запустить на своём устройстве [oracle virtualbox](https://www.virtualbox.org/wiki/Downloads)

Установите программу с официального сайта и разверните на ней gazebo-2

При запуске может возникать следующая ошибка:

![1](assets/simulator/1.png)

Чтобы её устранить нажмите "Изменить настройки сети" и после открытия следующего окна просто согласитесь с изменениями, нажав "ОК"

![2](assets/simulator/2.png)

После успешного запуска откроется окно рабочего стола VirtualBox

![3](assets/simulator/3.png)

## Настройка виртуальной машины

Для тестирования своего кода на виртуальной машине сначала необходимо узнать IP устройства, для этого в окне рабочего стола VBox вызываем терминал `Ctrl + Alt + t` и вводим команду `ip a`, в строке inet написан IP устройства

![4](assets/simulator/4.png)

С рабочего стола запускаем приложения `Lasertag Slim + ROS2` и `QGroundControl`, ждём загрузки приложений

После успешной загрузки `Lasertag Slim + ROS2` мишень загорается красным

![5](assets/simulator/5.png)

В `QGroundControl` может возникнуть ошибка `Navigation error`. Для её устранения дождитесь получения сигнала

![6](assets/simulator/6.png)

После успешного подключения окно `QGroundControl` должно выглядеть так

![7](assets/simulator/7.png)
